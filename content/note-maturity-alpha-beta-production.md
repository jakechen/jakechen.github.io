Digital garden stages measure **epistemic maturity** (how battle-tested an idea is), not **topic difficulty** (101 vs. 300 level). A 300-level architecture starts as an `Alpha` when unverified; a 101-level workflow reaches `Production` once settled.

Traditional gardening labels (*Seedling / Budding / Evergreen*) are ambiguous outside note-taking circles. For now, every note here uses the software release lifecycle:

* **`Alpha`** — Unverified hypothesis, mental model, or single-conversation takeaway. *(This note is `Alpha`—digital gardening is completely new to me.)*
* **`Beta`** — Bench-tested in code, hardware, or a live workflow, with edge cases still emerging.
* **`Production`** — Validated across repeated runs with documented failure guards and links into `[[atomic-notes-and-mocs]]`.

**TL;DR:** Publish complex ideas early at `Alpha` without waiting for a finished essay; promote a note only after testing it against reality.
